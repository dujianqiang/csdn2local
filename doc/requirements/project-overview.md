# csdn2local 项目需求概述

csdn2local 是一个本地 Web 工具，用于保存公开 CSDN 文章及栏目的正文、图片、代码和必要排版，以便离线阅读和长期保留。归档保存在本地。

## 初始版本

- **单个网页下载**：提交一篇公开文章的链接，同步生成 HTML、PDF 或 Markdown，默认 HTML。再次保存时更新所选格式，保留其他格式及其资源。下载记录支持按标题、域名、原始 URL、作者和标签搜索。
- **栏目批量下载**：提交公开专栏或专题链接，按原有顺序保存指定篇数或全部文章。后台显示进度，每次生成一种带目录的 HTML、EPUB、PDF 或 Markdown。已保存的版本可从历史记录打开，失败文章可逐篇重试或导入浏览器另存的 HTML。
- **样式优化**：统一单篇和专题的导航、首屏表单、进度和结果展示，支持窄屏、键盘操作和按文件类型筛选下载记录。

完整规格和待验收事项见 [OpenSpec 需求索引](../../openspec/README.md)。安装、归档路径和操作步骤见 [使用说明](../../README.md#使用说明)。
