## Why

许多网站可能停止运营或下线内容，导致有价值的 CSDN 文章无法继续访问。本变更为本地小工具建立文章归档能力，将公开文章正文保存为可离线访问的文件，为后续迁移到其他存储或平台提供基础。

## What Changes

- 新增 Web 服务，支持提交单个公开 CSDN 文章 URL。
- 提取文章正文及正文相关资源，排除评论、广告、推荐和侧边栏等非正文内容。
- 按用户选择生成 HTML、PDF，或同时生成两种格式；未指定时默认生成 HTML。
- 将文章及元数据保存到项目根目录下的 `data/`，按域名和文章目录组织。
- 对重复 URL 执行覆盖保存，只保留最新版本。
- 对资源缺失、格式生成失败等情况保留可用产物，并向用户报告具体问题和提供重试入口。
- 新增单一关键词搜索入口，按文章元数据模糊匹配并定位本地 HTML 或 PDF 文件。

## Capabilities

### New Capabilities

- `csdn-article-archiving`: 导入公开 CSDN 文章，提取正文，生成可选格式并保存到本地。
- `local-article-search`: 基于本地文章元数据进行关键词检索并打开归档文件。

### Modified Capabilities

无。仓库当前没有已有能力规格。

## Impact

- 新增 Web 服务界面和同步下载处理流程。
- 新增 CSDN 页面解析、正文资源下载、HTML/PDF 生成、本地文件存储和元数据索引能力。
- 新增本地 `data/` 文件目录及文章归档结构。
- 需要选择并引入适合页面解析、PDF 生成和本地索引的技术依赖。
