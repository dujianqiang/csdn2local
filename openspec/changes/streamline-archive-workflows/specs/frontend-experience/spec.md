## ADDED Requirements

### Requirement: 归档操作可以继续和恢复

系统 SHALL 为新建下载、查看记录和继续查看进行中的专题提供明确入口，并在等待、失败和完成时提供与当前状态匹配的下一步操作。

#### Scenario: 在首屏开始新任务或查看已有归档

- **WHEN** 用户打开单篇或专题下载页面
- **THEN** 地址和主要按钮在已有记录之前，且提供跳到记录的链接。专题低频选项可展开设置

#### Scenario: 等待下载表单提交

- **WHEN** 用户启用交互脚本并提交有效的下载表单
- **THEN** 页面显示等待状态，并在当前提交完成前阻止重复提交

#### Scenario: 继续查看进行中的专题

- **WHEN** 专题任务运行期间用户回到专题页
- **THEN** 页面提供返回当前任务的链接。启用脚本时进度在原页更新，任务结束后显示结果。禁用脚本时可以继续查看最新状态

#### Scenario: 修改失败或已完成任务的参数

- **WHEN** 用户从结果页选择修改设置
- **THEN** 下载表单保留原始地址、格式以及适用的专题并发数量。结果页优先提供可打开的本地文件

#### Scenario: 通过安装包运行服务

- **WHEN** 用户从构建好的 Python 安装包启动 Web 服务
- **THEN** 下载页面可加载其样式和交互脚本
