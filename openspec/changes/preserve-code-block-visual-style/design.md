## Context

离线 HTML 由 `render_article_document` 统一生成，目前只为 `pre` 提供基础背景和横向滚动。正文中的代码文本和特殊字符已经保留，因此本次只需要调整生成文档的 CSS，不引入前端构建或额外主题依赖。

## Goals / Non-Goals

**Goals:**

- 让代码块接近截图中的深色、等宽、卡片式阅读效果。
- 保持原始换行、缩进、连续空格和 ASCII/Unicode 边框字符。
- 让长代码行在离线页面中可横向滚动。

**Non-Goals:**

- 不复制 CSDN 的 VIP 标识、复制按钮、目录和点赞等页面外壳。
- 不实现完整的 CSDN 语法高亮主题或交互式代码复制功能。

## Decisions

- 在生成 HTML 的内联 CSS 中统一设置 `pre` 的深色背景、浅色文字、等宽字体、圆角、内边距和横向滚动。
- 设置 `pre`/`code` 的 `white-space: pre`，避免 HTML 渲染折叠空格或换行；通过 `overflow-x: auto` 处理宽代码块。
- 让 `code` 继承代码块颜色和字体，保留正文中已有的语法高亮 class，不依赖远程 CSS。
- 用 HTML 单元测试检查样式声明和边框字符仍存在于输出内容中。

## Risks / Trade-offs

- **深色样式不完全等同于原站主题** → 采用稳定的离线内联样式，优先保证可读性和无网络依赖。
- **代码块在窄屏上需要横向滚动** → 保留滚动行为，避免强制换行破坏 ASCII 图形和代码缩进。

## Migration Plan

无需数据迁移。重新下载文章即可生成带新样式的 HTML；已有 HTML 不会自动修改。
