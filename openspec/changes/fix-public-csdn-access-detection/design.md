## Context

当前 `PageFetcher` 在整份 HTML 中搜索登录/付费关键词。CSDN 公开页面会携带隐藏的充值、会员或推荐组件，因此通用文案可能出现在页面中，但并不代表正文访问受限。

## Goals / Non-Goals

**Goals:**

- 只在有明确证据表明页面需要登录或付费时拒绝归档。
- 允许包含隐藏通用 WAF、充值和会员组件的公开文章继续进入正文解析流程。
- 用自动化测试固定该行为，并用用户提供的公开 URL 做回归验证。

**Non-Goals:**

- 不改变 CSDN 正文选择器、资源下载、归档格式或搜索逻辑。
- 不绕过真正的登录、付费、验证码或站点访问控制。

## Decisions

- 删除对整页通用 `付费专栏` 文案的拒绝判断，因为它可能来自隐藏页面组件。
- 保留重定向到 `passport`/`login` 主机的拒绝判断，以及明确的正文访问提示（如“登录后查看”“请登录后阅读”）。
- 将判断逻辑保持在页面抓取层，解析层仍负责在正文不存在时返回“未找到正文”，避免通过模糊关键词推断访问权限。
- 使用 `respx` 模拟页面响应，覆盖隐藏充值组件仍返回成功；使用用户 URL进行真实网络回归，确认能进入归档流程。

## Risks / Trade-offs

- **某些付费页面使用不明显的提示文案** → 先让正文解析和输出阶段暴露失败；后续可基于真实样本增加精确、上下文相关的识别规则。
- **CSDN WAF 返回临时 521** → 保留具体 HTTP 状态错误，后续可单独增加重试或浏览器请求策略，不把 521 误报成付费文章。

## Migration Plan

无需数据迁移。替换应用代码并重启本地服务即可；原有 `data/` 归档文件和 SQLite 索引保持不变。
