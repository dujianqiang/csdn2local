## Context

专题单篇重试已通过后台任务更新归档，并能从正文缓存或旧 HTML、EPUB 读取已保存的正文。专题结果页和历史详情共用文章列表模板。

## Goals / Non-Goals

一次提交对应一个进度任务和一次归档发布，使用当前版本的输出格式、原文顺序和下载并行配置。继续支持单篇重试及上传另存的 HTML。

## Decisions

- 文章行使用复选框，两个批量按钮放在重新下载专题所在操作区。「重试全部失败」由服务端按归档当前状态选取目标。仅显示失败的筛选保留已有勾选，按钮显示勾选数量。
- 重试任务共用专题下载的分批抓取逻辑。按位置合并结果，一次性暂存并发布，沿用旧正文和资源读取逻辑。这样每批只需一次归档合并和导出，发布前原归档仍可读取。
- 已归档文章的重试失败原因显示在本次结果页，原正文和成功状态继续有效。原本失败的文章继续显示重试后的失败原因。旧归档沿用现有可重建条件。

## Risks / Trade-offs

- 旧结果页可能滞后于归档状态。批量提交按当前归档验证位置，工作线程开始时重新读取归档。全部失败模式按最新状态选取失败文章。
- 批量任务复用专题任务的互斥执行和暂存目录发布，避免同一版本同时重建以及导出失败时丢失原归档。
