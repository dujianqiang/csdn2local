## ADDED Requirements

### Requirement: 批量重试专题文章

系统 MUST 在含有文章且支持重建的专题结果页或历史详情提供「批量重试」和「重试全部失败」操作。

#### Scenario: 重试勾选的成功和失败文章

- **WHEN** 用户勾选已完成文章、失败文章或两种状态的文章，并提交「批量重试」
- **THEN** 系统在一个任务中重新抓取这些文章，并显示本次重试进度。未勾选文章保持原状态和正文

#### Scenario: 重试全部失败文章

- **WHEN** 用户提交「重试全部失败」
- **THEN** 系统以当前专题版本的失败文章为本次目标，勾选状态和列表筛选不影响处理范围。没有失败文章时操作不可用

#### Scenario: 批量更新归档

- **WHEN** 批量重试中至少有一篇成功
- **THEN** 系统按原顺序更新当前归档版本及其文章状态。若已有正文的文章重试失败，系统保留旧正文并在结果页显示本次失败原因

#### Scenario: 无可发布的更新

- **WHEN** 所选文章均重试失败或专题导出失败
- **THEN** 系统显示失败原因，已有的可用归档仍可打开

#### Scenario: 提交无效选择

- **WHEN** 用户提交空选择或当前专题不存在的文章位置
- **THEN** 系统报告提交错误，归档不发生变化
