## Why

当前首页只有搜索入口，用户无法直观看到已经下载到本地的文章文件。增加已下载文件列表后，用户打开 Web 服务即可浏览和继续访问已有归档，减少重复搜索和重复下载。

## What Changes

- 在首页增加“已下载文件”列表，展示本地索引中的已归档文章。
- 列表按最近保存时间倒序排列，优先展示最新下载的文章。
- 每条记录只展示文章标题和本地文件地址，并沿用 HTML 优先、PDF 回退的打开规则。
- 保留现有关键词搜索；输入关键词时列表显示匹配结果，未输入关键词时显示全部已下载文章。
- 没有任何下载记录时显示明确的空状态提示。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `local-article-search`: 增加首页浏览已下载文章列表、按最近保存时间排序和空状态展示要求。

## Impact

- 修改本地文章索引查询，增加按保存时间获取全部记录的能力。
- 修改首页路由和模板，增加已下载文件列表及空状态展示。
- 增加 Web 层和索引层测试，不引入新的外部依赖或数据迁移。
