## Context

上一轮设计建立了“本地文章档案馆”的视觉语言，但首页采用“先叙事、再保存台、后档案索引”的垂直节奏。根据反馈，核心任务的视觉位置和权重仍不足；本次只调整信息架构和首屏权重，不推翻已有色彩、字体和组件系统。

## Goals / Non-Goals

**Goals:**

- 让用户在首屏一眼看到 URL 输入框和“开始保存”。
- 让标题为任务服务，减少与主要操作竞争的装饰性文案。
- 让格式选择成为 URL 之后的轻量设置，而不是并列的第二个主入口。
- 让档案索引保留价值，但明确成为首屏之后的次级区域。

**Non-Goals:**

- 不改动专题下载的业务能力或后端任务流程。
- 不引入弹窗、向导或前端状态管理。
- 不新增自动聚焦、自动提交或其他可能打断用户的行为。

## Decisions

### 首屏采用“任务台 + 轻叙事”二栏

首页首屏改为左侧短标题和一句价值说明，右侧一个大面积浅色任务台。任务台内按“文章地址 → 保存格式 → 开始保存”的顺序排列，主按钮使用唯一的珊瑚色高权重处理。原来的深色“保存之后”说明面板移出首屏，避免形成第二个同等重量的视觉区域。

```text
┌──────────────────────────────────────────────────────────────┐
│  csdn2local                               单篇下载  专题下载  │
├─────────────────────────┬────────────────────────────────────┤
│  把网页保存成自己的档案   │  现在保存一篇文章                   │
│  一句说明                 │  文章地址                          │
│                          │  [ https://blog.csdn.net/...      ] │
│                          │  保存格式  HTML / PDF              │
│                          │  [ 开始保存 ]                       │
└─────────────────────────┴────────────────────────────────────┘
                         ↓
                 档案索引 / 搜索本地文章
```

### 缩减首屏文案和视觉竞争

移除首屏中的“保存之后”编号说明和额外的三条卖点；这些信息不是用户开始任务所必需的。输入框高度、标签对比度和按钮尺寸增加，表单面板与背景之间保留明显的纸张色差和阴影，使其成为唯一的实心高亮区域。

### 保留既有设计 token

继续使用现有墨蓝、纸张色、珊瑚橙和衬线标题，不新增颜色或装饰。变化集中在网格比例、间距和组件权重，确保这是同一产品的聚焦迭代，而不是重新换肤。

### 响应式规则

桌面端保持左右二栏，任务台占据约 55% 宽度；窄屏时标题和任务台堆叠，但任务台紧跟标题出现，档案索引继续位于其后。按钮保持完整中文文案，不使用只靠图标表达的操作。

## Risks / Trade-offs

- [风险] 首屏说明减少后，用户可能少看到产品能力介绍 → [缓解] 在任务台旁保留一句价值说明，并把详细内容放到表单内的短辅助文案。
- [风险] 大任务台在窄屏占用较长垂直空间 → [缓解] 减少上下间距并保持输入、格式、按钮的紧凑顺序。
- [风险] 过度强调单篇任务可能弱化专题入口 → [缓解] 顶部导航保留并明确显示“专题下载”，不把专题入口藏到次级链接中。
