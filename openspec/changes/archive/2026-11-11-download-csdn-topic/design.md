## Context

当前项目已经具备单篇 CSDN 文章的抓取、正文清理、资源下载、HTML/PDF 输出、本地存储和受控文件访问能力。专题下载需要在这条单篇流水线上增加专题页面解析、顺序编排、统一输出和前端功能切换，同时不能改变已有单篇下载行为。

## Goals / Non-Goals

**Goals:**

- 从一个公开专题地址解析出有序的文章列表。
- 支持可配置并行数量，默认并行数量为 1；在提高并行度后仍按专题原始顺序编排结果。
- 将成功文章合并为一个带导航的 HTML、EPUB 或 PDF 文件，三者只能选择一种。
- 复用单篇正文和资源处理逻辑，避免专题和单篇产生不同的正文结果。
- 在前端提供单篇下载和专题下载两个清晰的功能入口。

**Non-Goals:**

- 第一版不支持多个专题同时提交、后台队列或专题全文搜索；专题内部允许有限并发下载。
- 不把专题输出拆成多个用户可选的最终文件；每次专题任务只提交一种输出格式。
- 不改变单篇文章已有的保存格式、目录结构和本地搜索语义。

## Decisions

### 1. 顺序解析和可配置并发处理

专题解析器从专题页面提取文章链接，按页面出现顺序建立有序列表，并对规范化后重复的 URL 去重但保留首次位置。专题任务使用有界并发执行单篇下载，默认并发数为 1，用户可以通过专题表单调整为有效的正整数。每个任务携带原始序号，结果收集后按序号排序再生成导航和最终输出。

并发数量由服务端校验并限制为正整数；并发只影响下载执行速度，不改变文章顺序。默认值设为 1，便于保持与单篇下载相同的网络压力和调试行为。

### 2. 复用单篇文章处理流水线

专题任务只负责专题页面抓取、文章顺序、失败记录和最终编排；每篇文章的正文提取、资源下载、代码格式保留和错误转换继续复用现有服务。专题编排接收每篇文章的规范化正文模型，而不是重新抓取或解析已保存 HTML。

这样可以保证专题输出和单篇下载遵循相同的正文范围、代码样式和资源处理规则。

### 3. 三选一输出格式

专题表单使用单选控件，格式枚举为 `html`、`epub`、`pdf`，默认预选 HTML。服务端再次校验格式只能有一个；HTML 生成一个合并文档，EPUB 生成一个 EPUB 3 文件，PDF 使用合并后的离线 HTML 打印生成一个 PDF。

选择多种格式时返回参数错误，不隐式生成额外文件，避免用户误以为专题输出是多选任务。

### 4. 统一的专题导航模型

编排器先生成一个有序导航模型，包含专题标题、文章标题、顺序编号、成功状态和内部目标地址。HTML 使用文档内锚点，EPUB 使用 `nav.xhtml` 和章节内部链接，PDF 在首页生成可点击的目录/导航区域并按顺序插入文章内容。

单篇失败的文章仍保留在导航模型的原始位置，但以失败状态显示原因且不生成不可打开的链接；成功文章的导航地址全部指向专题输出内的本地内容，不再依赖 CSDN 在线地址。

### 5. 专题文件布局和提交

专题归档使用独立目录，例如：

```text
data/
└── <domain>/
    └── topics/
        └── <topic-key>/
            ├── topic.html   # 三选一
            ├── topic.epub   # 三选一
            ├── topic.pdf    # 三选一
            ├── metadata.json
            └── assets/
```

输出先写入暂存目录，只有在至少有一篇文章成功且最终单一输出生成成功后才提交专题目录和元数据。失败文章、原始专题地址、文章顺序、选定格式和警告写入 `metadata.json`。

### 6. 前端采用独立页面和共享导航

保留 `/` 作为“单个地址下载”页面，新增 `/topic` 作为“专题下载”页面；两个页面共享顶部功能导航。单篇页面沿用原有表单和结果页，专题页面使用专题 URL、并行数量、三选一格式和专题处理结果表单。并行数量默认显示为 1，输入非法值时在提交阶段给出明确提示。

## Risks / Trade-offs

- [专题页面结构变化] → 将专题链接选择器集中封装，保留规范化 URL 去重，并用多个专题页面样本建立解析测试。
- [专题文章数量过多导致同步请求过长] → 提供可调并行数量以缩短处理时间，同时限制为有界并发；后续再引入后台任务队列。
- [并发过高造成网络压力或触发站点限制] → 默认并行数为 1，服务端校验正整数并保留用户可调但有界的配置入口。
- [单篇失败造成专题内容不完整] → 继续处理后续文章，在导航原顺序位置展示失败状态和原因。
- [EPUB 目录或资源引用不规范] → 使用固定的 EPUB 3 包结构、`nav.xhtml` 和本地资源路径，并增加解包结构测试。
- [PDF 导航交互受渲染器限制] → 先保证首页目录和文章顺序可见，并使用离线 HTML 内部链接生成可点击导航。

## Migration Plan

不需要迁移已有单篇文章。升级后新增专题入口和 `data/<domain>/topics/` 目录；已有单篇目录继续按原路径访问。若回滚，只需移除专题路由、专题服务和模板，不影响既有单篇归档文件。
