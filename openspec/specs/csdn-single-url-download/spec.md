# csdn 单个连接下载 Specification

## Purpose

本项目用于将一个公开可访问的 CSDN 文章连接保存为本地文件，保留正文和必要资源，降低网站停止运营或文章下线造成的内容丢失风险，并为后续迁移到其他存储平台提供本地归档基础。

## Requirements

### Requirement: csdn 单个连接下载

系统 SHALL 以 Web 服务形式接受一个公开可访问的 CSDN 文章 URL，并同步提取正文、生成用户选择的 HTML 和/或 PDF 文件，保存到项目 `data/` 目录。系统 SHALL 仅保存正文及正文引用的必要资源，保留代码内容和必要格式，并通过本地元数据支持已下载文件列表与关键词检索。

#### Scenario: 使用默认格式保存单篇文章

- **WHEN** 用户提交一个无需登录即可访问的 CSDN 文章 URL，且未明确选择格式
- **THEN** 系统同步处理请求，默认生成 HTML，并将文章保存到本地

#### Scenario: 保存用户选择的格式

- **WHEN** 用户提交一个公开 CSDN 文章 URL，并选择 HTML、PDF 或两种格式
- **THEN** 系统同步处理请求，并尝试只生成用户选择的格式

#### Scenario: 拒绝不支持的访问范围

- **WHEN** 文章需要登录、付费或其他受限访问权限
- **THEN** 系统报告明确失败原因，不将请求视为成功归档

#### Scenario: 只提取文章正文

- **WHEN** 页面同时包含文章正文、评论、广告、推荐、侧边栏或其他页面外壳
- **THEN** 归档文件只包含文章标题、正文和正文所需资源，不保存非正文内容

#### Scenario: 保存正文资源到本地

- **WHEN** 正文引用图片或其他必要资源
- **THEN** 系统将资源保存到文章目录的 `assets/` 下，并让离线 HTML 使用本地相对地址

#### Scenario: 保留代码内容和视觉格式

- **WHEN** 正文代码包含注释、换行、缩进、空白或 ASCII/Unicode 边框字符
- **THEN** 归档 HTML 保留这些内容和有意义的排版；代码块使用深色样式，默认折叠且可以展开

#### Scenario: 打印和 PDF 保持代码可见

- **WHEN** 用户打印归档 HTML 或选择生成 PDF
- **THEN** 代码内容不会因网页折叠状态被隐藏

#### Scenario: 使用稳定的本地目录结构

- **WHEN** 文章归档成功或部分成功
- **THEN** 文件保存到 `data/<domain>/<article-key>/`，并包含可用输出、`metadata.json` 和正文资源；文章目录使用文章 ID 加清理后的标题命名，无法获取 ID 时使用稳定回退名称

#### Scenario: 重复下载覆盖旧版本

- **WHEN** 用户再次保存同一个文章 URL
- **THEN** 系统用最新结果覆盖当前归档，不保留旧版本作为活动文件

#### Scenario: 单项失败保留可用结果

- **WHEN** 单个正文资源下载失败，或 HTML/PDF 中一种格式生成失败
- **THEN** 系统保留其他可用产物，报告缺失资源或失败格式及原因，不让整篇文章整体失败

#### Scenario: 搜索和浏览已下载文件

- **WHEN** 用户打开首页或输入标题、域名、原始 URL、作者或标签关键词
- **THEN** 首页无关键词时按最近保存时间倒序展示全部已下载文件，有关键词时展示匹配结果；每条只显示标题和本地地址，HTML 优先、PDF 回退，没有记录时显示空状态

#### Scenario: 限制本地文件访问

- **WHEN** 用户打开列表中的本地地址
- **THEN** 服务只允许访问 `data/` 下已归档的文件，不暴露任意文件系统路径或暂存目录
